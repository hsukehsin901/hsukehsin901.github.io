## 怎麼寫新文章

最簡單的方法：用 [Pages CMS](https://app.pagescms.org) 登入 GitHub，選這個 repo，就有編輯器可以寫文章、選分類、上傳圖片。

也可以直接在 `_posts` 資料夾新增一個檔案，檔名格式是 `年-月-日-英文或數字.md`，例如 `2026-10-05-hello.md`，開頭寫：

```
---
layout: post
title: "文章標題"
date: 2026-10-05 10:00:00 +0800
categories: [musings]
tags: ["日常"]
---
內文從這裡開始。
```

## 分類

| 分類 | categories 要填 | 子分類（tags）例子 |
|---|---|---|
| 童話 | `fairy-tales` | 格林童話、神話與傳說、其他故事 |
| 旅遊 | `travel` | 奧瑞行、川藏行、馬來西亞、旅遊猜謎… |
| 碎碎念 | `musings` | 死用說明、周公、日常 |
| 翻譯心得 | `translation` | 找碴英語 |

章節順序、說明文字、子分類按鈕都在 `_config.yml` 裡改。
